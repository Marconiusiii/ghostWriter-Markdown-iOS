# Te damos la bienvenida a ghostWriter Markdown

ghostWriter Markdown es una aplicación de escritura en texto sin formato para crear notas, artículos, listas, documentación y cualquier otra cosa que quieras expresar con palabras.

Markdown añade estructura mediante unos cuantos signos de puntuación comunes. Tus documentos siguen siendo legibles como texto sin formato y puedes renderizarlos cuando quieras ver el formato final.

Este documento es tuyo. Léelo, edítalo o duplícalo antes de experimentar.

## Markdown en un minuto

Un documento Markdown sigue siendo solo texto. Los caracteres como almohadillas, asteriscos y corchetes indican a una aplicación cómo debe presentar algunas partes del texto.

Por ejemplo, una almohadilla seguida de un espacio crea un encabezado. Un guion seguido de un espacio crea un elemento de lista.

No necesitas memorizarlo todo. Insertar, en el editor, puede añadir por ti elementos comunes de Markdown, y Referencia de Markdown, en Acciones de archivo, contiene una guía rápida de sintaxis.

## Organiza el contenido con encabezados

Los encabezados dividen un documento en secciones con significado. También facilitan la navegación por documentos largos mediante Esquema y la navegación por encabezados de un lector de pantalla.

# Encabezado principal

## Encabezado de sección

Añade más almohadillas para subsecciones más profundas. Markdown admite seis niveles de encabezado.

Procura usar los niveles de encabezado en orden, en vez de elegirlos por su tamaño visual.

## Crea listas

Usa guiones o asteriscos para crear una lista con viñetas:

- Primera idea
- Segunda idea
- Tercera idea

Usa números para indicar una secuencia:

1. Redacta el documento
2. Revisa el texto
3. Comparte el archivo final

Cuando Listas automáticas está activado, al pulsar Retorno continúa la lista actual. Pulsa Retorno en un elemento de lista vacío para terminar la lista.

También puedes crear una lista de tareas:

- [x] Aprende los conceptos básicos
- [ ] Escribe algo interesante
- [ ] Renderiza el documento final

## Añade énfasis

Rodea el texto con un solo asterisco para darle énfasis:

*Este texto aparece en cursiva al renderizarse.*

Usa dos asteriscos para darle énfasis fuerte:

**Este texto aparece en negrita al renderizarse.**

Usa dos virgulillas a cada lado para marcar algo como eliminado o que ya no se aplica:

~~Este plan ha cambiado.~~

Usa el énfasis cuando aporte significado. Una frase clara suele ser más útil que decorar cada palabra importante.

## Crea enlaces e imágenes

Escribe el texto visible del enlace entre corchetes y la dirección entre paréntesis:

[Visita el sitio web de ghostWriter](https://marconius.com/fun/ghostWriter/)

Una imagen utiliza una sintaxis parecida, con un signo de exclamación al principio:

`![Una descripción útil de la imagen](https://example.com/image.jpg)`

La descripción entre corchetes es el texto alternativo. Describe lo importante de la imagen para que una persona que no pueda verla reciba la misma información útil.

Para marcar un archivo SVG, PNG o JPG adjunto como gráfico táctil, añade el título exacto tactile: `![Mapa táctil](map.svg "tactile")`

La dirección de una imagen puede apuntar a un archivo adjunto o a un archivo de internet. Renderizar una imagen externa puede ponerse en contacto con el servidor que la aloja.

## Cita a alguien

Empieza una línea con el signo mayor que para crear una cita en bloque:

> La buena escritura comienza con algo que vale la pena decir.

Las citas pueden contener varias líneas y otros elementos de Markdown.

## Separa ideas

Tres guiones solos en una línea crean una regla horizontal:

---

Una regla horizontal marca un cambio de tema o una separación significativa entre secciones.

## Muestra código o texto literal

Usa una comilla invertida alrededor de un fragmento corto de código o texto que deba tratarse de forma literal, como `Comando-S`.

Usa tres comillas invertidas antes y después de un ejemplo de código más largo:

```swift
let appName = "ghostWriter Markdown"
print(appName)
```

Puedes añadir de forma opcional el nombre de un lenguaje después de las comillas invertidas iniciales.

## Crea una tabla

Usa barras verticales entre las celdas y una fila de guiones debajo de los encabezados de columna:

| Función | Qué hace |
| --- | --- |
| Insertar | Añade elementos de Markdown |
| Esquema | Enumera los encabezados del documento |
| Renderizar | Muestra el resultado con formato |
| Acciones de archivo | Abre los comandos del documento |

Los encabezados de columna con significado ayudan a todo el mundo a entender una tabla, incluidas las personas que navegan por ella con un lector de pantalla.

Insertar puede crear esta estructura por ti. Elige el número de columnas y filas y, después, sustituye los nombres de columna generados y las celdas vacías por tu propio contenido.

## Usa el editor

El editor mantiene visible la puntuación de Markdown para que siempre controles el texto de origen.

- Insertar añade encabezados, enlaces, listas, tablas, citas, código y otros elementos.
- Esquema enumera tus encabezados y te permite ir directamente a uno.
- Renderizar abre la versión con formato del documento.
- Acciones de archivo ofrece opciones para guardar, compartir, cambiar el nombre, navegar y consultar la Referencia de Markdown.

ghostWriter guarda automáticamente después de que dejes de escribir durante un momento y cuando la aplicación pasa a segundo plano. Guardar ahora solicita que se guarde de inmediato.

## Tus documentos e iCloud

Los documentos se guardan en En este dispositivo, a menos que elijas iCloud Drive en Ajustes.

Cuando iCloud Drive está activado, los archivos siguen siendo documentos Markdown normales dentro de la carpeta ghostWriter Markdown. Puedes abrirlos y editarlos desde otra aplicación o dispositivo compatible.
