# Welcome to ghostWriter Markdown

ghostWriter Markdown is a plain-text writing app for creating notes, articles, lists, documentation, and anything else you want to express with words.

Markdown adds structure using a few ordinary punctuation marks. Your documents remain readable as plain text, and you can render them whenever you want to see the finished formatting.

This document is yours. Read it, edit it, or duplicate it before experimenting.

## Markdown in a Minute

A Markdown document is still just text. Characters such as number signs, asterisks, and brackets tell an app how parts of that text should be presented.

For example, a number sign followed by a space creates a heading. A dash followed by a space creates a list item.

You do not need to memorize everything. Insert in the editor can add common Markdown elements for you, and Markdown Reference in File Actions contains a quick syntax guide.

## Organize with Headings

Headings divide a document into meaningful sections. They also make longer documents easier to navigate with Outline and a screen reader's heading navigation.

Use one number sign for the main heading:

# Main Heading

Use two number signs for a section:

## Section Heading

Add more number signs for deeper subsections. Markdown supports six heading levels.

Try to use heading levels in order instead of choosing them for their visual size.

## Make Lists

Use dashes or asterisks for a bulleted list:

- First idea
- Second idea
- Third idea

Use numbers for a sequence:

1. Draft the document
2. Review the text
3. Share the finished file

When Automatic Lists is enabled, pressing Return continues the current list. Press Return on an empty list item to end the list.

You can also create a task list:

- [x] Learn the basics
- [ ] Write something interesting
- [ ] Render the finished document

## Add Emphasis

Wrap text in single asterisks for emphasis:

*This text is italicized when rendered.*

Use two asterisks for strong emphasis:

**This text is bold when rendered.**

Use two tildes on each side to mark something as removed or no longer applicable:

~~This plan has changed.~~

Use emphasis when it adds meaning. A clear sentence is usually more helpful than decorating every important word.

## Create Links and Images

Put the visible link text in square brackets and the address in parentheses:

[Visit the ghostWriter website](https://marconius.com/fun/ghostWriter/)

An image uses similar syntax with an exclamation mark at the beginning:

`![A useful description of the image](https://example.com/image.jpg)`

The description inside the square brackets is alternative text. Describe what matters in the image so someone who cannot see it receives the same useful information.

Images in Markdown refer to files on the web. Rendering an external image may contact the server that hosts it.

## Quote Someone

Begin a line with a greater-than sign to create a block quote:

> Good writing begins with something worth saying.

Quotes can contain multiple lines and other Markdown elements.

## Separate Ideas

Three dashes on a line by themselves create a horizontal rule:

---

A horizontal rule marks a change of subject or a meaningful break between sections.

## Show Code or Literal Text

Use a backtick around a short piece of code or text that should be treated literally, such as `Command-S`.

Use three backticks before and after a longer code sample:

```swift
let appName = "ghostWriter Markdown"
print(appName)
```

You can optionally put a language name after the opening backticks.

## Build a Table

Use pipes between cells and a row of dashes beneath the column headings:

| Feature | What It Does |
| --- | --- |
| Insert | Adds Markdown elements |
| Outline | Lists document headings |
| Render | Shows formatted output |
| File Actions | Opens document commands |

Meaningful column headings help everyone understand a table, including people navigating it with a screen reader.

Insert can build this structure for you. Choose the number of columns and rows, and then replace the generated column names and empty cells with your own content.

## Use the Editor

The editor keeps the Markdown punctuation visible so you always control the source text.

- Insert adds headings, links, lists, tables, quotes, code, and other elements.
- Outline lists your headings and lets you jump directly to one.
- Render opens the formatted version of your document.
- File Actions provides saving, sharing, renaming, navigation, and the Markdown Reference.

ghostWriter saves automatically after you pause typing and when the app moves into the background. Save Now requests an immediate save.

## Your Documents and iCloud

Documents are stored On This Device unless you choose iCloud Drive in Settings.

When iCloud Drive is enabled, the files remain ordinary Markdown documents inside the ghostWriter Markdown folder. You can open and edit them from another compatible app or device.
